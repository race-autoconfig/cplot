All functions
=============


Plot functions
--------------


This package provides visualizations for:

- Parameter configurations using parallel coordinates with [param_parallelcoord][param_parallelcoord].

- Sampling distributions with [param_boxplot][param_boxplot], [param_histplot][param_histplot], [param_pairplot][param_pairplot], [param_heatmap][param_heatmap], [param_jointplot][param_jointplot] and [param_sunburst][param_sunburst].

- Configurations performance (training and testing) with [qual_boxplot][qual_boxplot], 
  [qual_heatmap][qual_heatmap] and [qual_scatter][qual_scatter].
